# Einführung in JavaScript und TypeScript

Dieses Repository enthält die Übungen für unsere Einführung in JavaScript und TypeScript.

## Voraussetzungen

Für die Teilnahme brauchst du auf deinem Computer die folgenden Programme:

- **Git**
  - Damit klonst du dieses Repository. Zur Not kannst du es von GitHub auch als zip-Datei herunterladen.
- **Node.js (mindestens Version 24.x)**
  - Wir führen auch TypeScript-Dateien direkt mit Node.js aus. Achte deshalb bitte auf die Version, denn mit älteren Versionen funktioniert das unter Umständen nicht.
  - Du kannst Node.js hier für alle Betriebssysteme herunterladen: https://nodejs.org/en/download
  - Mit `node -v` kannst du die installierte Version prüfen.
- **einen Editor oder eine IDE mit Unterstützung für JavaScript und TypeScript**
  - [Visual Studio Code](https://code.visualstudio.com/) bringt alles Nötige mit.
  - WebStorm und IntelliJ IDEA mit Ultimate-Abo funktionieren ebenfalls.
  - IntelliJ IDEA ohne Ultimate-Abo unterstützt JavaScript und TypeScript erst ab Version 2026.1.
  - Node.js prüft die Typen nicht. Die TypeScript-Fehler zeigt dir deshalb nur dein Editor an.

Prüfe bitte auch, ob du auf deinem Computer die nötigen Rechte hast:

- Du musst dieses Repository von github.com klonen oder herunterladen können (dürfen).
- Du musst auf deinem Computer Node.js ausführen können (dürfen).

> [!NOTE]
> **Bitte schalte während des Online-Workshops deine Kamera an**, damit wir uns sehen können 🎥. Mikrofon hingegen bitte nur anmachen, wenn Du etwas sagen oder fragen möchtest (was Du natürlich jederzeit darfst!)

## Vorbereitung

1. Klone dieses Repository:
   ```bash
   git clone https://github.com/nilshartmann-workshops/2026-11-11-js-ts-intro.git
   ```
2. Öffne das geklonte Verzeichnis in deinem Editor oder deiner IDE.

Installieren musst du sonst nichts, ein `npm install` ist also nicht nötig.
